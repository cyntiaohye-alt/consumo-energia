# Calculadora de Consumo de Energia ⚡️ 
Projeto desenvolvido em Python para calcular o consumo mensal estimado de aparelhos eletrônicos.

💡 Como funciona
O usuário informa:
➡️ Nome do aparelho
➡️ Tempo médio de uso diário
➡️ Potência do aparelho em Watts
Depois o sistema calcula o consumo mensal em kWh.

🧮 Fórmula:
consumo_mensal = (potencia_aparelho * tempo_medio_uso_diario * 30)/1000
